# Workshop-paper deadline calendar (ML / RL / NLP)

**Kind:** reference — a venue/timing accumulator, not a research topic. Purpose: know which
workshop-paper wave a given project doc could target, so "workshop paper" in a project doc
can be tied to a concrete date. Time-sensitive: every entry carries its intake date, and
all dates below were reported by an assistant with web search (intake 2026-08-22; query
made in early August 2026 — several listed deadlines were already past at intake). **All
dates are unverified against the venue pages** — check the linked call before relying on
one.

Source: two answers to Danielle's questions (logged verbatim in `../../danielle-inputs.md`).
